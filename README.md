# Mlord

Mlord is an Android manga reader based on the existing project source. The application keeps the local reader, manga sources, search, chapters, downloads, favorites, history, database, networking, parsers, image cache, and offline reading functionality.

The Android package is `com.mlord.app`. GitHub Actions builds the release APK from `.github/workflows/build-android.yml`.
